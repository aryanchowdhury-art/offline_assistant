Symbol queries

Deterministic  Extracts the real code from disk right now. No hallucination possible.
You typeYou get
show me the signature of XExact signature line(s)
show me the full source of XEntire function/class body
paste the function XFull source
give me the definition of XFull source
find the class XFull class source

Where X is a function, method, or class name anywhere in the project. The app walks every .py file, finds the definition, returns the real code.

If X doesn't exist: you get "X is not defined in any .py file under the current project roots." — never fake code.

Copilot mode — Ctrl+Shift+Space

How to use

  1. Open a file in VS Code (or Notepad).
  2. Focus VS Code (click on it).
  3. Press Ctrl+Shift+Space.
  4. Type your question in the dialog.
  5. Enter.

If the capture fails, a file picker opens — pick any file manually.

What it loads

  • The active file's full content
  • Its Python imports (one level deep)
  • Any file you mention by name in the question

Backing up

The one file you can't lose:

Copy-Item "E:\offline_assistant\data\user_profile.json" `
          "$env:USERPROFILE\Desktop\user_profile_backup.json"

Do this after every significant session where the assistant learned something new about you.

Rebuilding the exe

Run this whenever you've edited any .py file:

cd E:\offline_assistant
E:\.venv\Scripts\python.exe -m PyInstaller offline_assistant.spec --noconfirm
Copy-Item -Recurse -Force "model" "dist\OfflineAssistant\model"
Copy-Item -Recurse -Force "data"  "dist\OfflineAssistant\data"
Copy-Item -Force "offline_assistant.ico" "dist\OfflineAssistant\offline_assistant.ico"

Troubleshooting

SymptomFix
"Active window is not a recognized editor" Click on VS Code first, then press Ctrl+Shift+Space. Or click Help Me for a file picker.
"Could not locate X under configured workspace roots" Add the folder via Copilot → Project → Add folder…
Copilot hotkey does nothing Only works when VS Code / Notepad is focused. Use Help Me button instead.
Assistant writes fake code Only for symbol queries. If it happens, the file isn't .py or has a syntax error.
Assistant says "I don't know you" Intercept pattern didn't match. Try what do you know about me verbatim.
Model says something weird The 3B model sometimes hallucinates. Ask for the same info via show me the signature of X or what do you know about me.
App won't launch Run from source to see the error: E:\.venv\Scripts\python.exe main.py
Out of RAM Lower n_ctx to 4096 in app/config.py. Rebuild.

Deterministic vs. LLM

Symbol "not found"PythonExact

"Explain X"LLM (with real file)Usually right

Rule of thumb: if you need exact, use show me. If you need understanding, use explain. If you need creative, just ask.

What the app will never do

  • Send anything to the internet
  • Write a file without your click
  • Touch a file outside your configured project roots
  • Remember something you didn't save to user_profile.json
  • See your unsaved VS Code edits (use Ctrl+S or copy the selection)

The three numbers to remember

6
recent chat messages injected per prompt
10
max related files loaded per Copilot call
200
files listed in a project snapshot

Change any of them in app/config.py if needed.

When something feels off

  1. Check the terminal — any Python traceback there explains what broke.
  2. Look at the [loaded: ...] line in the chat — it shows exactly what files the LLM saw.
  3. Ask show my profile as JSON — proves the profile system is alive.
  4. Ask show me the signature of <any function you know exists> — proves the extractor works.
  5. If all else fails: python main.py from source, paste the error.
